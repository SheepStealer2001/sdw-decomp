Controls

      

        
Left drag
, or move the object under the cursor

        
Middle drag

        
Right drag

        
Click again
pick the object behind the one picked

        
Wheel
move the view forward and back

        
Double-click
look at that point

        
WASD
move the view

        
Shift+drag
move the object up and down

        
Q E
turn the object (with Shift: finely)

        
Arrows
nudge the object (with Shift: further)

        
G
drop the object to the ground

        
F
look at the object

        
Ctrl+D
copy the object

        
Delete
remove it (again: bring it back)

        
Ctrl+S
save
